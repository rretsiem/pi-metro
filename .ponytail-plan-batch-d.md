## D1 — METROL_DISABLE_SWEEP env var (~10 min)

Files: `src/sweep.ts`, `src/index.ts`, `test/sweep.test.ts`.

**Approach:** export a `isSweepDisabled()` helper that reads `process.env.METROL_DISABLE_SWEEP` once (truthy = "1"/"true"). In `index.ts session_start`:
- If disabled, skip the immediate `sweepMetrolStorage(rootDir)` call.
- If disabled, do not schedule the periodic `setInterval(..., STORAGE_SWEEP_INTERVAL_MS)`.
- Existing one-shot sweep export remains available; no behavior change for callers who want to invoke it directly.

Rationale: small surface, single env var, test verifies both gating paths.

**Test (test/sweep.test.ts):**
- `isSweepDisabled()` returns true with `METROL_DISABLE_SWEEP=1` set; false otherwise.
- `isSweepDisabled()` reads once (subsequent `process.env` mutation does not flip after first call) — make it lazy + memoized.
- (Optional wiring test) — given disabled state, calling the gating wrapper returns no-op result without touching disk.

## D2 — shouldSkipPoll fingerprint (~20 min)

Files: `src/watch.ts`, `src/dispatcher.ts`, `test/watch.test.ts`.

**Approach:** replace the `mtimeMs <= lastSeen` check with a combined fingerprint `{ mtimeMs, fileCount, totalSize }`. `shouldSkipPoll(fingerprint, lastFingerprint)` skips only when both shapes are equal (deep-equal). When `lastFingerprint` is `null`, never skip.

Storage on the dispatcher: change `private lastSeenDirMtime: number | null = null;` → `private lastSeenDirFingerprint: DirFingerprint | null = null;` where `DirFingerprint = { mtimeMs: number; fileCount: number; totalSize: number }`. Compute fingerprint inside `poll()` after the directory contents are read.

Rationale: catches file rewrites that rewind mtime (NFS/FAT, `touch -d`), or files of the same name but different size. The mtime check is preserved as the cheapest component; fingerprint adds two more cheap fields.

**Test (test/watch.test.ts):**
- Equal fingerprints (mtimeMs + fileCount + totalSize) → skip.
- Older mtime but different fileCount → does not skip.
- Older mtime but different totalSize → does not skip.
- Newer mtime → does not skip (unchanged behavior).
- `null` lastFingerprint never skips (first poll), even when current fingerprint is `{0,0,0}`.
